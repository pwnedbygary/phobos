psp-measure's GE tests, round 6 (tools/psp-measure/ge.c in Phobos says what each test draws; docs/psp-core.md,
part 66, what each is for). Pictures: the target's pixels after one test, a little-endian 32-bit word each, row
by row, 256x256.
light-products-0..3: a lit point a pixel, row y's light (y, 255 - y, y) on column x's material (x, x, 255 - x),
normals (0, 0, 1), (33, 0, 56), (65, 0, 72), (101, 0, 26). light-sweep-0..7: 1024 normals in 8x8 blocks, each
with 64 products (light per row, material per pixel, levels 96-255 from a fixed sequence, white in each block's
first row and column). light-sum: 1 to 4 lights alike, 64 rows each.
recip-pixels, recip-projected: texels showing the GE's reciprocal at pixels (the chord's low 8 bits).
recip-vertex-0..2, recip-sprites: 4096 cells of 4x4 pixels at one w each (in [1, 2)), u 512.
texel-range: sprites whose texture coordinates are +-2^k plus a known part, k 8 to 23 (red: u mod 256).
patch-cull: 256 patches (PATCH_CULL_ENABLE, PATCH_FACING, mirroring, normals, culling, lighting, points);
patch-cull-edges: 64 patches against their cells' scissor rectangles, the near and far planes.
curves-count-v: points added up along v at 16, 63 and 64 divisions (columns 0-2), -v-65, -v-100, -v-128,
-v-200, -v-255 at that many (columns 3-7), one to a test.
time-*: the GE's drawing time. Records of words: case, size, CPU MHz << 16 | bus MHz, repeats | values << 16,
then per run `values` times in microseconds from just before sceGeListEnQueue: to the finish callback, to
sceGeListEnQueue's return, (time-signals) to the signal callback; 0xffffffff for a run not finished (a stall,
see <name>.stalled; a list sceGeListEnQueue refused: 0xffffffff, then its error). Each test at 222/111 MHz, then
at 333/166 (the clocks as found put back after). The cases (case: what; size):
time-commands 0: an empty list: FINISH and END; commands
time-commands 1: NOP; commands
time-commands 2: TEXTURE_ENV_COLOR, a register, each a new value; commands

time-commands 5: JUMP to the next word; jumps
time-commands 6: CALL to a RET elsewhere; calls
